Polynym API Prototype

Caller-aware identity disclosure using JWT and role-based filtering

Prototype purpose

This frontend demonstrates one core feature of Polynym: the same person record returns different identity data depending on the caller role.

HR View

Expected result: legal name only.

Public View

Expected result: chosen or preferred name only.

Self View

Expected result: full identity access for the person themselves.
