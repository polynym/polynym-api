Polynym Identity Management API

Secure caller-aware identity management using JWT authentication and role-based access control

System overview

This web interface shows how Polynym handles identity requests from different authenticated caller roles. HR, Public, Self and Medical users query the same person record, but the API returns only the identity data permitted for that role.

HR View

Expected result: legal name only.

Public View

Expected result: chosen or preferred name only.

Self View

Expected result: full identity access for the person.

Medical View

Expected result: legal and chosen name only.

Right of erasure (GDPR Article 17)

Only the data subject may erase their own record. All identity records are removed; the audit entry is retained without any reference to the erased person.
